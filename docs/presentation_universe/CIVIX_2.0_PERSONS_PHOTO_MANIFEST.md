## MANIFEST RULES (READ BEFORE EXECUTING)

**Priority Order:**
1. `OPEN_SOURCE_SEARCH` — Search first. Use Wikimedia Commons, Unsplash, Pexels, Pixabay, archive.org, Delhi Police press release archives, Indian court/legal photo databases. Max 2 search attempts per person.
2. `GENERATE_SYNTHETIC` — Only if open-source search fails or returns unsuitable results.
3. `NO_PHOTO` — Hard-coded. Do NOT attempt to source or generate. Record the documented reason only.

**Format Standards:**
- Booking/custody photos: White or grey background, front-facing, number board if appropriate, harsh institutional lighting
- Dossier portraits: Neutral background, front-facing, semi-formal
- Witness/civilian portraits: Neutral background, natural lighting, appropriate clothing for role
- Composite sketches: Hand-drawn pencil/charcoal style, police sketch aesthetic
- Surveillance frames: Grainy, low-resolution, partial face, CCTV timestamp overlay

**Output naming convention:** `PHOTO_[PERSON_ID]_[TYPE].jpg`
- TYPE: `BOOKING`, `DOSSIER`, `CIVILIAN`, `SKETCH`, `SURVEILLANCE`, `PROFESSIONAL`

**For persons needing 2 images:** Name them `PHOTO_[ID]_01.jpg`, `PHOTO_[ID]_02.jpg`
